# stack-and-queue-implementation
A C++ implementation of Stack and Queue data structures using arrays and linked lists. Covers basic operations like push, pop, enqueue, dequeue, and peek.
# 📚 Stack & Queue Implementation (C++)

This repository contains implementations of two fundamental data structures:

* Stack (LIFO - Last In First Out)
* Queue (FIFO - First In First Out)

---

## 📌 Topics Covered

### 🔹 Stack

* Push
* Pop
* Peek / Top
* isEmpty

### 🔹 Queue

* Enqueue
* Dequeue
* Front
* isEmpty

### ✅ Queue
